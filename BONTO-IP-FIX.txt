Bonto 내부 Host 재작성 접속 수정 - 2026-11-12
적용: server.js와 bonto-proxy.json을 프로젝트 루트에 함께 교체 후 Save / Restart.
기존 v61.3 버전 및 게임 기록은 유지합니다. hodon-data와 field-records.*를 삭제하지 마세요.
확인된 실제 로그: hostBonto=false, remote=internal, cf=visitor, real=internal, rayValid=true, xff=[internal].
실제 IP는 존재하지만 내부 Host 재작성 때문에 기존 도메인 조건에서 거부되던 문제를 보완했습니다.
동일 IP 1접속 제한은 유지됩니다.
중요: bonto-proxy.json은 Bonto 전용 신뢰 설정입니다. Cloudflare가 방문자 IP 헤더를 덮어쓰고 Bonto가 이를 내부 게이트웨이를 통해 전달한다는 배포 경계를 명시합니다. CF-Ray 형식 자체는 인증 수단이 아닙니다.
새 VM으로 이전할 때 bonto-proxy.json을 삭제하거나 HODON_BONTO_CF_RELAY=0으로 설정하고 VM의 실제 중계 구성을 적용하세요.
IP 검증, 다른 IP 허용, 같은 IP 차단, 새로고침/재접속, 방 생성/버전 호환: 26 테스트 통과.
