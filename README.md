# 호돈 게임방 v14 — 윷놀이 + 무료 가상칩 바둑이

## 설치 및 기존 게임 교체
1. ZIP을 풀고 HODON-GAMEROOM-v14 폴더 **안의 파일**을 기존 서버 프로젝트 최상위에 올립니다. 폴더를 한 단계 더 중첩하지 마세요.
2. 기존 field-records.json이 있다면 보존하세요. 이번 ZIP에는 전적 파일이 포함되지 않습니다.
3. 새 package.json/package-lock.json을 포함해 전체 파일을 함께 교체하고 npm install(또는 npm ci)을 실행하세요.
4. 서버를 재시작하세요. Bonto에서는 저장 후 Restart를 실행합니다.
5. 모든 참가자는 새로고침하세요. Mac Chrome: Command + Shift + R. 상단 온라인 · v14를 확인하세요.
6. 바둑이 탭 → 닉네임 → 인원 2~4명 → 기본 판돈과 시작 금액 → 새 방 만들기. 친구는 링크 또는 코드로 참가할 수 있습니다. 관전 입장 버튼도 있습니다.

운영 중인 외부 서버에 자동 배포한 상태는 아닙니다. 위 교체와 재시작이 필요합니다.

## 금액 설정
- 기본 판돈: 1~1,000,000 가상칩.
- 1인당 시작 금액: 기본 판돈의 2배 이상, 최대 1,000,000,000 가상칩.
- 같은 방의 모든 참가자에게 동일한 시작 금액을 줍니다.
- 다음 판은 남은 칩을 이어서 사용합니다. 방장은 매 판 칩을 초기화하거나 진행 중 금액을 수정할 수 없습니다.
- 칩이 없는 사람은 다음 판에서 제외됩니다. 칩이 남은 참가자가 최소 2명 있어야 새 판을 시작할 수 있습니다.
- 게임 안에서만 사용하는 무료 가상칩입니다. 현금 거래/결제/환전 기능은 없습니다.
- 방과 칩은 서버 메모리에 보관합니다. 재시작하면 방·바둑이 칩은 초기화됩니다. 기존 윷놀이 전적 저장 방식은 유지됩니다.

## 바둑이 진행
- 기본 판돈을 납부하고 각자 4장의 카드를 받습니다.
- 첫 베팅 → 아침 교환 → 베팅 → 점심 교환 → 베팅 → 저녁 교환 → 최종 베팅 → 공개 및 정산.
- 각 교환에서 0~4장을 선택합니다. 0장은 스탠드/패스입니다.
- 다이, 체크, 콜, 하프, 따당, 올인을 지원합니다. 가능한 버튼만 활성화됩니다.
- 하프: 콜 후 팟의 절반, 최소 기본 판돈/최소 인상액을 충족하는 인상입니다.
- 따당: 현재 라운드 금액 2배 이상이며 최소 인상액을 충족합니다.
- 라운드당 정규 인상은 최대 4회입니다. 부족한 콜은 보유 칩만 내고 올인합니다.
- 짧은 올인은 이미 행동한 사람의 재인상 권한을 열지 않습니다.
- 메이드 > 베이스 > 투베이스 > 원베이스. 유효 카드 수가 같으면 높은 숫자부터 비교해 더 낮은 쪽이 이깁니다. A는 1입니다. 무늬 우열은 없습니다.
- 동률은 분배하며 나머지 1칩은 딜러 다음 자리부터 승자에게 배분합니다. 올인 금액이 다르면 사이드팟을 별도로 계산합니다.
- 전원이 다이하면 남은 1명에게 팟을 주고 카드를 공개하지 않습니다.
- 카드가 부족하면 현재 손패와 이번에 버리는 카드를 제외하고 앞서 버린 카드만 다시 섞습니다.
- 시간 초과 시 체크 가능하면 체크, 콜이 필요하면 다이. 교환 차례는 스탠드합니다.

한게임의 수동 베팅과 로우 바둑이 흐름을 참고한 독립 구현입니다. 한게임의 소스·이미지를 복제하거나 전체 서비스 기능을 이식한 제품은 아닙니다. 아침벳/점심벳 강제 자동 베팅 등 별도 변형 규칙은 이번 버전에 포함하지 않았습니다.

## 관전과 방 관리
- 관전자는 대기실에 닉네임과 연결 상태가 표시됩니다.
- 종료 전에는 자기 손패 이외의 카드값을 서버에서 전송하지 않습니다. 관전자는 종료 전 모든 패가 뒷면으로 표시됩니다.
- 공개 승부에서는 다이하지 않은 참가자의 카드만 공개합니다.
- 방장은 플레이어와 관전자를 강퇴할 수 있습니다. 진행 중인 플레이어 강퇴는 해당 패를 포기 처리합니다.
- 재접속은 기존 브라우저의 저장된 참가 토큰으로 복구합니다. 같은 브라우저 탭 여러 개는 같은 참가자로 재접속될 수 있습니다. 여러 사람 테스트에는 서로 다른 브라우저/프로필을 사용하세요.
- 참가자는 진행 중 다른 게임으로 이동할 수 없습니다. 판이 끝난 뒤 방에서 나가 상단 탭으로 게임을 선택하세요. 관전자는 언제든 나갈 수 있습니다.

## 디자인
- 승인한 시안의 초록·금색, 타원 테이블, 카드 4장, 호돈 얼굴, 우측 방 정보·관전자·기록·족보 구성을 코드로 구현했습니다.
- 이미지 시안과 픽셀 단위로 100% 동일한 복제는 아니며 화면 크기에 따라 간격과 패널 배치가 달라집니다.
- 휴대폰에서는 패널이 아래로 배치됩니다. 자신의 손패는 아래쪽에 표시됩니다.
- 카드 배분/교환 단계 전환과 정산 표시 애니메이션이 있습니다.
- 기존 윷놀이의 팀 공용 말 UI·잡았다 효과를 포함합니다.

## 검증 및 한계
npm test: 자동 검사 40개 통과.
- 기존 윷놀이 규칙과 20판 UI 회귀 시뮬레이션.

- 실제 운영 서버 또는 여러 실제 iPhone/MacBook 간 대전을 검증한 것은 아닙니다. 오류가 0개라고 보장할 수는 없습니다.
