# FIELD YUT ONLINE v4 — Bonto / Node.js

회원가입 없이 2~4인 초대 링크로 대전하는 윷놀이 프로토타입입니다. 게임머니/현금 베팅 기능은 없습니다.

## 이번 버전

- **2·3·4명 개인전** 및 **4명 2대2 팀전** 선택. 팀전은 1인당 3개의 말을 사용합니다. 0/2번 청팀, 1/3번 홍팀.
- **팀전 같은 팀 말 업기 / 같은 팀 말 잡기**를 선택할 수 있습니다. 팀원 한 명의 말 3개가 모두 완주하면 해당 팀 승리.
- **윷·모 추가 던지기 / 상대 말 잡기 시 추가 던지기**, 도·개·걸·빽도, 지름길 선택, 말 이동 가능 위치 안내.
- **낙**: 윷 던지기 세기를 10 미만 또는 90 초과로 설정하면 낙 처리됩니다. 실물 윷과 완전히 동일한 물리 판정은 아닙니다.
- **윷가락 애니메이션**, 플레이어별 말 현황, 진행 로그, 20/30/45/60/90초 제한시간 및 시간 초과 자동 윷 던지기/말 이동.
- **닉네임별 승/참가 기록 및 순위**를 `field-records.json`에 저장. 동명이인은 합쳐지며 계정 인증이 없습니다.

## Bonto 배포 방법

기존 앱과 같은 위치에 ZIP 압축을 풀고 다음을 **앱 최상위 루트**에 올려 주세요.

```
app.js
index.html
style.css
game.js
game.test.js
server.js
package.json
render.yaml
README.md
```

`field-yut/` 폴더 안에 이 파일들을 중복으로 넣지 않습니다. Bonto에서 Save → Restart 후 실제 주소로 접속하세요. `package.json`의 start 스크립트가 `node server.js`입니다. 기존 게임 중인 방은 서버 재시작 시 초기화됩니다.

로컬 개발: Node.js 20 이상 환경에서 `npm install`, `npm test`, `npm start`. 브라우저에서 `http://localhost:3000`.

## 아직 구현 범위에 포함되지 않는 것

**넷마블 윷놀이 완전 동일 제품이 아닙니다.** 넷마블 자체 그래픽/사운드/캐릭터/게임머니/미션/아이템·유료 기능/정확한 배수·벌금 시스템/윷 파워 게이지 물리 시뮬레이션을 복제하지 않았습니다. 공개된 기본 윷놀이 규칙과 팀전 특성을 참고한 독립 구현입니다. 세부 빽도·지름길·낙 예외는 추후 원작 게임 실기 검증이 필요합니다.

**기록 영구 보존 주의**: JSON 파일 기록은 호스팅 제공사가 파일시스템을 유지하는 동안만 보존됩니다. Bonto 앱 재배포·인스턴스 교체 시 데이터가 없어질 수 있습니다. 실제 영구 랭킹에는 별도 관리형 데이터베이스가 필요합니다. 아직 외부 DB 연결은 구현하지 않았습니다.

## 검증

`node --test game.test.js`로 이동·팀전·빽도·낙 등 13개 규칙 자동 테스트 통과. 실제 Bonto 4인 네트워크와 디바이스 동작은 배포 전 검증하지 못했습니다.
