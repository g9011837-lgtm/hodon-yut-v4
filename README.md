# 호돈 게임방 v61.3 통합본

이 ZIP 한 개에 전체 실행 파일과 실제 실행 화면이 들어 있습니다. 일부 파일만 덮어쓰면 클라이언트와 서버 버전이 달라질 수 있습니다.

## 적용

1. 현재 프로젝트와 운영 데이터를 백업합니다.
2. ZIP을 풀고 내용 전체를 hodon-yut-v4 저장소의 루트에 반영합니다. ZIP 자체를 올리는 방식이 아닙니다.
3. 기존 hodon-data 폴더, field-records 파일, .env 및 비밀 설정은 그대로 유지합니다. 이 통합본에는 운영 기록이나 비밀 설정이 포함되어 있지 않습니다.
4. GitHub main에 반영한 다음 Bonto에서 Pull from Remote를 실행하고 서버를 Restart합니다. 병합 충돌이 나오면 적용 완료가 아닙니다.
5. 브라우저를 강력 새로고침합니다. 이 패키지의 서버·클라이언트 버전은 모두 v61.3입니다.

## 실제 미리보기

preview/index.html을 열면 로비와 8개 게임의 실제 실행 화면을 볼 수 있습니다. preview/lobby-comparison.html에는 승인된 로비 시안과 실제 실행 화면을 함께 넣었습니다. 각 게임의 모바일 화면도 포함되어 있습니다.

- v61.3: 승인한 입체감 개선 시안의 둥근 나무 윷가락, 나뭇결과 단면, 착지·튕김·굴림·낙 연출을 적용했습니다.
- 모든 게임의 버튼·이름표·팝업에 같은 크림·금색·초록 재질과 그림자를 적용했습니다.
- 카드와 화투의 옆면, 오목돌 광택과 착수 반응, 알까기 말의 둥근 옆면과 충돌 반응을 보강했습니다.
- 쿵쿵따 정답 시 단어 블록·캐릭터 반응과 사천성의 연결·패 제거 효과를 적용했습니다.
- 게임 엔진의 규칙·말 수·판 구성·서버 판정과 v61.2 알까기 파워·마찰을 유지했습니다.
- 기본 이미지 생성으로 만든 새 윷가락 소재는 sculpted-yut-stick.svg/webp에 포함되어 있습니다. 프롬프트: approved reference matching honey-gold half-cylinder yut stick, vertical unmarked broad flat face, rounded back and semicircular end grain, longitudinal wood grain, upper-left light, transparent alpha, no UI or text. 렌더링·상호작용·동작은 실제 코드로 처리합니다.

- v61.3: 프로필 캐릭터의 음수 위치를 없애 상단 로고 침범을 수정하고, 소리·설정의 중복 배경을 가렸습니다.
- 모든 게임의 화면·입력창·버튼·팝업에 Black Han Sans 서체를 적용했습니다. 원본 사진의 폰트 파일을 알 수 없어 형태가 가까운 서체를 사용했습니다. 메뉴 이름도 이미지 글자 대신 실제 텍스트로 표시합니다.

- 밝은 스타디움 로비, 작은 4×2 게임 메뉴, 게임별 계급·경험치·전적과 넓어진 방 목록.
- 10종 호돈 아바타와 말을 같은 캐릭터로 연결. 닉네임은 독립적으로 변경 가능.
- 게임별 스타디움 배경과 입체적인 테이블·캐릭터·사천성 음식 패.
- 기존 게임 규칙과 베팅 선택지는 유지. 7포커와 섯다의 추가 선택지는 '추가 베팅' 안에 있습니다.
- 알까기는 요청한 크기별 질량과 마찰력 조정을 유지했습니다.
- 정상 화면의 서버 통합·버전 문구는 숨기고 실제 연결 오류는 계속 안내합니다.

계급·경험치·참가자·카드·점수·남은 패는 실제 게임 데이터입니다. 시안에 있는 예시 숫자를 고정 표시하지 않습니다.

## 동일 IP 동시 접속 제한 (2026-11-10)

- 한 공인 IP에서 로비·관전·게임을 합쳐 한 연결만 허용합니다. 추가 접속은 서버에서 차단합니다.
- 새로고침은 서버 발급 재접속 키로 이어지고, 창을 닫으면 IP 점유를 해제합니다.
- 같은 와이파이·공유기의 다른 기기도 동시에 이용할 수 없습니다.
- server.js와 두 클라이언트 파일을 함께 적용하고 Bonto Restart 후 강력 새로고침하세요.
- 기본 단일 Node.js 프로세스에 적용됩니다. 프록시·운영 관련 세부 사항은 IP-CONNECTION-POLICY.md에 있습니다.
- 이번 검증: 자동 테스트 338개 통과(건너뜀 없음), 별도 브라우저 프로필의 중복 차단·새로고침·기존 창 유지·종료 후 재접속 확인.
- 이전 캐릭터·한글 글꼴 수정도 모두 포함되어 있습니다.

preview/single-ip.webp에서 실제 차단 안내 화면을 볼 수 있습니다.

## 섯다 인원 확장 (2026-11-10)

- 2장 섯다는 최대 10명, 3장 섯다는 최대 6명입니다. 화투 20장을 사용합니다.
- 3장 선택 시 참가 인원은 6명까지 표시하며 서버도 초과 인원을 거부합니다.
- 덱에서 꺼낸 패를 제거하는 기존 방식을 유지하여 같은 패를 두 사람에게 배분하지 않습니다. 같은 월의 서로 다른 두 장은 정상입니다.
- 6~10명 섯다는 이름·보유칩·손패가 겹치지 않도록 전용 좌석 배치를 적용했습니다.
- 2장 10인 300판 및 3장 6인 100판에서 중복 패·덱 보존·칩 보존과 비공개 패를 검사했습니다.
- 실제 10인+관전자 테스트에서 서로 다른 IP 접속, 20장 중복 없음, 히든 패 비공개, PC·모바일 좌석 비중첩을 확인했습니다.
- 이번 전체 테스트 341개 통과. 이전 동일 IP 제한·캐릭터·한글 글꼴 수정도 모두 포함합니다.
