# 호돈 윷놀이 v7 — 고급 UI 개선

기존 v6의 실시간 게임 서버와 2~4인 / 2대2 팀전 규칙을 유지하며, 실제 브라우저에서 실행되는 화면의 디자인을 개선했습니다.

## 변경사항
- 상단: 호돈 얼굴 사진 로고, 금색 타이틀 및 전반적인 고급 게임 UI
- 윷판: 황금색 테두리, 양피지/나무 느낌의 그라디언트와 얼굴 워터마크
- 윷 던지기: 입체적인 윷가락, 조작 패널과 윷판 분리 유지
- 결과 연출: 도/개/걸/윷/모/빽도 결과를 윷판 중앙에 금색/보라색 효과로 표시
- 말: 호나우두 실제 얼굴 사진을 쓰고 팀별 색으로 구분
- 참가자: 사진 아바타 추가
- 우승: 호돈 얼굴, 금색 테두리, 트로피 연출
- 하단 게임 안내·진행 기록·랭킹 및 하단 초대 영역 유지
- 데스크톱/태블릿/모바일 반응형 조정

## 기존 배포 업그레이드
`index.html`, `style.css`, `app.js`, `hodon-face.png`를 같은 이름으로 교체하면 됩니다. `server.js`는 v6에서 사진 파일을 제공하던 버전을 유지하세요. 신규 저장소로 배포하는 경우 ZIP 안의 전체 파일을 GitHub 저장소 최상단에 업로드합니다.

## 실행
`npm install && npm start` 후 `http://localhost:3000`에 접속하세요.

## 검증
- `node --check app.js`, `node --check server.js` 성공
- `node --test game.test.js` 기존 13개 테스트 통과
- **실제 Bonto 4인 멀티플레이와 모든 브라우저 시각 효과는 아직 테스트하지 못했습니다.**
- 화면은 컨셉 이미지의 미술 방향을 참고한 실제 DOM/SVG/CSS 구현이며, 시안과 픽셀 단위로 완전히 동일하지 않습니다.


## v8 — 게임 연출 수정

- 윷판의 실제 호돈 얼굴 말은 SVG 원형 클리핑으로 렌더링하고, 우측 대기 말에도 얼굴 이미지가 나타납니다.
- 도/개/걸/윷/모/빽도/낙: 서버가 전달하는 고유 던지기 ID를 이용하여 모든 참가자에게 한 번씩 큰 글자 효과를 표시합니다.
- 우승 시 승리자 닉네임 + 폭죽 입자와 떨어지는 색종이 애니메이션을 표시합니다.
- 이 버전은 v7 기반의 부분 업데이트입니다. `app.js`, `style.css`, `index.html`, `server.js`, `hodon-face.png`를 기존 Bonto 앱 최상위에 넣어주세요.
- 서버를 재시작하면 진행 중인 게임방은 초기화됩니다.
