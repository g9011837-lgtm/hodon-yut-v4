# 호돈 윷놀이 v9.1 — 표시/이펙트 복구판

기존 v8 게임 규칙, 팀전, 기록 기능은 그대로 유지하면서 화면 효과 문제만 수정했습니다.

## 바뀐 점
- `app.js`에 호돈 얼굴 이미지를 내장했습니다. `hodon-face.png` 파일 경로가 잘못되어도 윷판 위 말과 우측 말 목록에 얼굴을 표시합니다.
- 윷을 던졌을 때 서버가 돌려주는 응답에서 바로 도/개/걸/윷/모/빽도/낙 애니메이션을 실행합니다. 기존 브로드캐스트 이벤트도 유지하고 중복 이펙트를 방지합니다.
- 승리 시 전체 화면 우승자 이름과 폭죽/색종이 효과를 표시합니다.
- `index.html`의 JS/CSS 주소에 `?v=9.1`을 추가하고 `server.js`에 캐시 방지 헤더를 넣었습니다.
- 화면 상단의 온라인 문구에 v9 표기가 나타나므로 새 코드가 실제 적용됐는지 확인할 수 있습니다.

## 설치: GitHub → Bonto
1. `app.js`, `index.html`, `style.css`, `server.js` 네 파일을 GitHub 저장소 최상위에 **교체**합니다. 별도 `field-yut` 폴더 안에 넣지 않습니다.
2. `hodon-face.png` 파일은 함께 업로드해도 좋지만, 게임 말 이미지는 `app.js`에 내장되어 있으므로 말 표시에는 필수가 아닙니다. 우승 화면과 로고에는 이 PNG가 필요합니다.
3. GitHub에서 각 파일의 최근 커밋이 바뀌었는지 확인합니다.
4. Bonto가 GitHub 변경사항을 자동 반영하지 않는다면 Bonto 코드 편집기에서 위 파일을 각각 교체하거나 Git에서 새로 가져옵니다. **GitHub만 수정한다고 기존 Bonto 앱의 파일이 반드시 자동으로 바뀌지는 않습니다.**
5. Bonto Save → Restart. 브라우저 강력 새로고침: Mac Chrome `Command + Shift + R`.
6. 화면 우측 상단 온라인 문구에 **v9**가 보이지 않는다면 여전히 예전 코드로 실행 중인 것입니다. 그때는 게임 규칙을 수정하지 말고 Bonto에서 실제 `app.js`가 업데이트됐는지 확인하세요.

## 검증
- JavaScript 구문 검사 통과
- 기존 게임 규칙 자동 테스트 13개 통과
- 라이브 Bonto 브라우저/서버 동작은 여기서 검증하지 못했습니다.
