적용 방법
1. 기존 코드를 백업하세요.
2. ZIP 안의 코드 파일 7개를 모두 기존 파일과 같은 위치에 덮어쓰세요. 한 번에 올릴 수 있습니다.
3. 파일 저장이 모두 끝나면 Restart를 한 번 누르세요.
4. www.호돈.com에서 Cmd+Shift+R로 강력 새로고침하세요.
적용방법.txt와 FONT-LICENSE-NOTO.txt는 코드로 올리지 않아도 됩니다.
'원격에서 가져오기'가 아닌 코드 파일 덮어쓰기 방식입니다.

변경
- 시작 시 큰 3 → 2 → 1 → START 카운트다운. 카운트다운 중 조작 불가.
- 경기 종료 시 우승자/최종 순위/점수/클리어/공격·상쇄 기록 팝업. 닫기와 방장 다시 시작.
- 30초마다 낙하 간격 90ms 감소. 처음 800ms → 710 → 620 → 530 → 440 → 350ms.
- 10줄 클리어마다 추가 60ms 감소. 최저 80ms. 새 경기는 처음 속도로 초기화.
- 서버 판정과 내 화면 예측에 동일한 시간별 속도 적용.
- 로비 게임 선택 5열 × 2행: 기존 9개 + 새 게임 준비 중 1칸. 준비 중은 클릭 불가.
- 테트리스 헤더/타이머/버튼 재정렬.
- 모든 게임에 선명한 Noto Sans 고딕체 적용: 본문 보통, 제목만 적당한 굵기.
- PC와 390px 모바일 메뉴 배치 확인.

기존 8개 게임 규칙, 배너와 텔레그램 링크, 전적·닉네임 저장 방식 유지.
hodon-data, 기록 JSON과 브라우저 사이트 데이터를 삭제하지 마세요.
